# Icons

The interface's icons come from the
[Papirus icon theme](https://github.com/PapirusDevelopmentTeam/papirus-icon-theme)
by the Papirus Development Team, under the GNU GPL v3 (`LICENSE`), as of
commit `072a55a`. They keep their Papirus names; the app draws them in the
color of the text, whatever color the files carry.

| File | From `Papirus/16x16/` |
|---|---|
| `computer.svg`, `computer-laptop.svg` | `devices/` |
| `configure.svg`, `edit-find.svg`, `list-add.svg`, `list-remove.svg`, `quickopen.svg`, `run-build.svg` | `actions/` |
| `view-fullscreen.svg`, `view-restore.svg` | `actions/` |
| `view-split-left-right.svg`, `view-split-top-bottom.svg` | `actions/` |
| `window-close.svg`, `window-maximize.svg`, `window-minimize.svg`, `window-restore.svg` | `actions/` |
| `vcs-branch.svg` | `actions/giggle-branch.svg` |
| `utilities-terminal.svg`, `utilities-system-monitor.svg` | `symbolic/apps/…-symbolic.svg` |
| `network-workgroup.svg` | `symbolic/places/network-workgroup-symbolic.svg` |
| `text-x-generic.svg` | `symbolic/mimetypes/text-x-generic-symbolic.svg` |

`terminal-prompt.svg` is the `$_` of `utilities-terminal.svg` alone, for
the tiles of tabs, which are the terminal's square themselves.
`node-hex.svg`, Node's hexagon, and `activity-pulse.svg`, the pulse on the
tiles of monitors, are Lex's own.
