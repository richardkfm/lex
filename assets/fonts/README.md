# Fonts

`JetBrainsMono-*.ttf` are [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono),
under the SIL Open Font License 1.1 (`OFL.txt`).

`SymbolsNerdFontMono-Regular.ttf` is the symbols-only font of
[Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) v3.4.0
(`NerdFontsSymbolsOnly.zip`), each icon a cell wide, under the MIT License
(`LICENSE.nerd-fonts`). Its icons come from the sets Nerd Fonts gathers, as
Font Awesome, Material Design Icons, Codicons, Devicons and Octicons, under
their own licenses, which
[Nerd Fonts lists](https://github.com/ryanoasis/nerd-fonts/blob/master/LICENSE).
